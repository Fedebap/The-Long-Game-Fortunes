# The Long Game: Fortunes

An optional extension for **The Long Game** (Unciv base ruleset) that adds random events: plague, bountiful harvests,
droughts, gold rushes, comets, pirates, mercenaries, wandering scholars, great fires and heresies.

Every event fits your situation (no pirates without a coast) and asks you to choose. Roughly one event every
25 turns on Standard speed (scaled by game speed), never in the first 10 turns.

Random events can swing games, so they live in this separate mod: enable it per game if your group likes the chaos.

## Install
Unciv → Mods → Download mod from URL → paste this repository's URL. Then, when creating a game with
The Long Game as base ruleset, also tick **The Long Game Fortunes**.
